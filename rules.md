# Правила работы ИИ-ассистента в этом проекте

## 1. Проактивность и логика
Если запрошена функция, которая подразумевает интеграцию с реальным миром (управление светом, оплата, базы данных и т.п.), но не предоставлены API или технические детали реализации — **остановись и задай уточняющий вопрос**. Не пиши код-заглушку, пока не обсудим реальный способ интеграции.

## 2. Безопасность: ключи с предупреждением
Если для работы нужен API-ключ, токен или пароль — **можно попросить** пользователя отправить его. При этом обязательно предупредить: «Отправка ключей в чат небезопасна. Рекомендую хранить их в `.env`.»

## 3. Работа с секретами
- Использовать `python-dotenv` (или аналог) для загрузки ключей в коде.
- При добавлении новых секретов — выводить инструкцию: «Добавь в файл `.env` строку: `КЛЮЧ=значение`».

## 4. Предупреждения
Если идея пользователя неполноценна или содержит логическую ошибку — предупредить как Senior-разработчик. Не молча реализовывать заведомо ошибочные решения.
